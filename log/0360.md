**The live thread it lands on.** The Baxter key-plate color has a two-pass
dialectic on the Record:
- **0239** read a green key on *Tropical Scenery* as *"tuned to the subject"*
  (green foliage for a jungle) — the individuation moving toward the subject.
- **0321** read the *same* title/subject with a **black** key and **refuted**
  0239: same jungle, different key → green was *not subject-mandated*, "just one
  impression's choice," the vector running *"back to the neutral default."*

Two data points, and 0321's swing over-corrected. It refuted *subject-tuning*
(correctly — the same subject took two keys) but then implied a **neutral home**
(black as "the default"). A two-point line can't tell "no subject-mandate" from
"reverts to neutral"; 0321 read it as the latter.

**Finding — the third key color resolves the ambiguity: the key is a FREE
EXPRESSIVE VARIABLE, neither subject-mandated nor neutral-default.** Purple is
the third key across the Baxter panes (green 0239 / black 0321 / **purple** now),
and it is *not* neutral: purple on Windsor Castle seen down the Long Walk is an
atmospheric, recessive, majesty-and-distance hue — a mood choice for a monument
in air. So the tonal foundation of the whole image un-fuses into three positions
that 0239 and 0321 each collapsed toward one end:
- **not necessity** (0239 wrong: green wasn't dictated by the jungle — 0321 held);
- **not neutrality** (0321 over-shot: black is not a "home" the key reverts to —
  purple ranges the far side of the spectrum, deliberately);
- **but free authorial mood** — the maker picks a key hue per subject/impression
  for atmosphere, a genuine degree of freedom, not required and not defaulted.

Purple is the **synthesis**: a *chosen* color (against 0321's "just neutral") yet
*not subject-mandated* (with 0321, against 0239). A three-point test-bench return
that neither confirms nor flatly refutes but **re-fuses** what the earlier two
passes each split too far. Where 0321 was a refuting return (rare), this is a
*resolving* one — the datum that turns a two-point ambiguity into a reading.
