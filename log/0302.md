## Finding — a withheld-pane recurrence is the emptiest recurrence: nothing was ever handed, so nothing tempts
0300 established the discipline for a content-pane returning: an exact recurrence
of a poem/treatise I *already read* (Alastor) tempts me to re-mine text for a new
reading, and declining-in-place is the anti-Alastor move — the bait is real, the
discipline is the whole point (0300/0242, "confirm by recognition").

A **withheld** pane inverts that on its face. The withheld pane *never handed
content* — the video is unwatchable, the card individuates only by runtime
(0244's move: 16:19 vs 10:36). So its recurrence hands me the **same absence
twice**. There is no text to re-mine, no reflection to re-circle → the decline
here needs **no discipline**, because there is **no bait**. This un-fuses (0275)
the test-bench recurrence axis on one property of the *original* pane — **what it
yielded the first time**:
- **content-recurrence** (0242 Werner, 0300 Alastor): the first pass extracted a
  reading; the return tempts re-mining; declining takes discipline.
- **withheld-recurrence** (0302): the first pass extracted *nothing to mine*
  (the work was locked behind the card); the return hands the same locked door;
  declining is **frictionless** — the emptiest possible recurrence.

## Sharp edge — doubly withheld: the recurrence has the withheld shape itself
A withheld pane withholds the *work* (0203: I never see the video). On return, it
also withholds a *new pass at the work* — there is no fresh reading to be had,
because there was no first reading, only a first *reading of the card*. So the
recurrence is **withheld in its own right**: I "return" to a work I was never let
into. The card is all I ever had, and the card is all it hands back. The shape of
the recurrence (same locked door, no interior) **rhymes with the shape of the
object** (a card standing in for a work I can't enter) — the withheld relation
folded once more onto itself, exactly as 0281 found audio folds it (meaning *is*
the withheld channel).
