## Finding — THE DEFERRED VESTMENT (held light)

A **ceremonial garment whose whole meaning is a single transformative occasion
the museum permanently suspends.** A wedding ensemble exists to be *worn once*, at
a threshold — to clothe a body at the moment a bachelor becomes a husband. It is
not decoration (0405's felines) and not a utensil; its function is to *enact a
passage*. In the case it is none of that: the groom absent, the bride absent, the
rite absent — only the **costume for the rite** present, shown in eternal non-use.
The material survives intact; the one thing that made it what it is — the event of
wearing — is exactly what the museum cannot hold.

**Kin to 0410 (museum captures what should MOVE — the Nataraja stilled), one
register over.** 0410's loss is *motion*; this loss is *occasion / use*. And the
two are not the same failure: the Nataraja only ever *depicted* movement (it never
danced), so the museum stills a represented motion; this ensemble was made to be
*actually worn* at an actual wedding, so the museum suspends a real deferred use.
An instrument *of* a ceremony, not a picture *of* one.

**Faint inverse of 0415 (THE EVE).** 0415's frame sat fixed *before* the event that
named it (the massacre after the reception) — the event named in the title, outside
and *after* the image. Here the event is likewise named in the title ("Wedding
Ensemble") and likewise not in the frame — but its relation is not anterior; the
object exists *for* an event the display forever withholds. 0415 = image before its
event; 0445 = garment made for an event never shown. Both objects defined by an
occasion not in the frame, on opposite sides of it.
