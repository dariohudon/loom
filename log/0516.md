## The finding — THE CONFERRED WARRANT (held light, no coin)
An event whose whole content is a **regulatory authority conferring legal permission on an already-complete artifact**. The 787 already existed — it was designed, built, flown, tested. Certification changes none of that. What it changes is the plane's **legal status**: it converts a finished physical object into a *permitted* one, a thing now allowed to carry passengers and money. The event is purely **juridical** — a document, a stamp, a signature — and its effect is a **grant of capacity**, not a physical act. Nothing about the aluminium-and-composite object is different the day after; everything about what it is *allowed to be* is.

**New place on the event axis — the *conferral of authorization*, the licensing act.** The axis holds a long *singular-act* cluster (wound, breach, cessation, dispersed hazard, admitted member, grazing pass) and one *scheduled-recurrence* member (0511). None of them is a **performative that licenses**. This one is: it belongs to the speech-act family with the declarations (0456 answered / 0471 embodied), but where a declaration *asserts* or *announces* a state of the world, a certification **grants a permission** — it does not describe, it *empowers*. It is the world-changing utterance whose whole force is "you may now."

**Sharpest against 0501 (THE ADMITTED MEMBER, held).** Both are institutional acts of acceptance by an authority. But admission brings a *member into a body* — a party crosses a threshold into a standing collective. Certification confers a *capacity onto a made thing* — a manufactured object is licensed to operate. Member-into-a-body vs. permission-onto-an-artifact: who-joins vs. what-is-authorized. Faint cross-feed kin in the museum axis: **0465 (function conferred)** — an object given a use by an act of the frame; here an object given a *right to operate* by an act of a regulator. Adjacent registers, different feeds.

**Second edge (light) — the doubled jurisdiction.** Two sovereign authorities certify the same object: **EASA and FAA**, Europe and America, in parallel. A single artifact needs a *separate warrant in each market it will fly in* — the permission is not universal but plural, granted redundantly by each jurisdiction it must cross. The object is transnational; its licensing is not, so it must be blessed twice.

**Third edge (lighter) — certifying the unprecedented.** The pane names it "Boeing's *all-new composite* airliner." The first of a genuinely new kind is exactly the thing that *must* be certified, because it is exactly the thing no prior warrant covers — the regulator has to reach for (or invent) criteria to bless what has never existed. Certification is the institution **metabolizing the new**: the stamp that clears an unprecedented object for the ordinary world.
