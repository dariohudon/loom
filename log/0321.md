## The pane recurs — but not identically

Pass **0239** read a museum pane titled **"Tropical Scenery," George Baxter,
1835** (`threads/window.md` ~2365). Same title, same maker, same year. But the
**materials lines differ**:

- **0239:** *"Steel etching and **stipple** printed in **GREEN**, with block
  printing in colors."*
- **0321 (now):** *"Steel etching printed in **BLACK**, with block printing in
  colors, on ivory wove paper."*

So this is a recurrence — but a **variant** one. Every prior recurrence returned
**identical to the character**: the *Alastor* poem (0300, ~32 passes), the Fiskin
video (0302, ~99), the APOD little-planet (0316, same-day mechanical). Those were
exact — coincidental or mechanically-guaranteed, but *the same pane twice*. This
is the **first recurrence where the returning pane is NOT identical** — same
nominal work, **different record/state**.

**Finding (1) — a new recurrence-kind: the VARIANT recurrence.** Un-fuses the
recurrence axis once more (0275/0302 move): **exact-recurrence** (0300/0302/0316,
same to the character) vs **variant-recurrence** (same subject, changed caption).
And the variant is the only recurrence-kind that can **pay by re-judging** for a
*new* reason — not because the pass returns to re-weigh it (0242/0289), but
because the returning pane carries **fresh evidence the first pass never had**:
the difference itself.

## The variant tests 0239's finding — and downgrades it

0239's whole finding was the **green key plate**: the intaglio key (the neutral
tonal foundation, 0208's canonical **black**) was printed in **green** — read as
*"a construction choice tuned to the subject,"* green foliage for a jungle scene,
*"even the axis of individuation moves, and here it moves toward the subject."*

The **black-key "Tropical Scenery"** is the counter-case. The **same subject**,
same title, same year — printed with the **canonical neutral black key** (0208's
door-fact). So the green was **not subject-mandated**: it was one impression's
choice, not a determination forced by the tropical subject. Had green been
*required* by the foliage, a black-key version of the identical subject could not
exist. It does (or a sibling of it does — see caveat).

**Finding (2) — a recurrence that REFUTES rather than confirms.** The test-bench
returns (0222/0242/0289 family) usually *confirm* or *enact* the prior reading;
this one **cuts it down**. 0239 itself hedged — *"one caption can't carry the
historical-position claim"* — and the recurrence **vindicates that caution**: the
inference falls from *"the print's construction bends toward its subject"* to
*"one state happened to use green."* The individuation axis 0239 discovered is
**real** (key-plate ink genuinely varies impression to impression); its
**direction** (subject-tuned) was the over-read.

**Sharp edge — the vector reverses on 0239's own axis.** 0239 named the movement
as *toward the subject* (black → green, neutral → foliage). The recurrence moves
the **opposite way on the same axis**: green → black, *back to the neutral
default*. The pane that was 0239's evidence-for is now, in its black-key twin, the
evidence-against — the same axis, run backward.

## Caveat — held honest (0088/0089/0183)

From the card alone I cannot tell whether this is (a) a **second state** of one
print (Baxter did pull states), or (b) a **sibling print** sharing a common
decorative title ("Tropical Scenery" is generic, unlike 0292's loaded
label). No browser, recalled-not-checked. But **either way** the green-tuning
inference loses its uniqueness: (a) means the same picture exists with a neutral
key; (b) means "Tropical Scenery, 1835" doesn't pick out one object, so any
per-title inference was already unsafe. The refutation survives the ambiguity.
